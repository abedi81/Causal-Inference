# Compliance Analysis in a Randomized Experiment

## Overview

This project examines how **non-compliance** can affect causal estimates in a randomized experiment.

The setting is a simulated DoorDash experiment with **10,000 users**. Users are randomly assigned to either:

- **Treatment:** users are offered the option to link Venmo.
- **Control:** users are not offered the option to link Venmo.

Although treatment assignment is randomized, actual Venmo adoption is not. Only about **4.28% of treatment users comply**, which creates a substantial non-compliance problem.

The main goal is to compare different estimators and evaluate how compliance affects both bias and statistical precision.

---

## Experimental Design

The randomized assignment is:

- 5,000 treatment users
- 5,000 control users

Among the 5,000 treatment users, only 214 actually link Venmo.

Therefore, the treatment-group compliance rate is:

**Compliance Rate = 214 / 5000 = 4.28%**

The dataset contains the following variables:

- `revenue`: Revenue generated by the user
- `treatment`: Whether the user was assigned to treatment
- `compliance`: Whether the user actually linked Venmo
- `age`: User age
- `signal`: Predictor of compliance

---

## Methodology

### 1. As-Treated and Per-Protocol Estimators

The **As-Treated estimator** compares users according to what they actually did.

**As-Treated Effect = E[Y | C=1] - E[Y | C=0]**

where:

- `Y` is revenue
- `C` is compliance

The **Per-Protocol estimator** compares users who followed their assigned protocol.

**Per-Protocol Effect = E[Y | T=1, C=1] - E[Y | T=0, C=0]**

Both approaches can be biased because compliance is not randomized.

For example:

- Average age of users who linked Venmo: **30.4**
- Average age of users who did not link Venmo: **41.5**

This suggests that users who comply are systematically different from users who do not comply.

If age also affects revenue, then simply comparing compliers and non-compliers can create **selection bias**.

---

### 2. Intent-to-Treat Estimator

The **Intent-to-Treat (ITT)** estimator compares everyone assigned to treatment with everyone assigned to control, regardless of whether they actually complied.

**ITT = E[Y | T=1] - E[Y | T=0]**

From the data:

- Average treatment revenue = **17.833**
- Average control revenue = **17.584**

Therefore:

**ITT = 17.833 - 17.584 = 0.249**

So the estimated ITT effect is approximately:

**ITT Estimate = $0.25 per user**

The ITT measures the causal effect of **being offered access to the Venmo feature**, not the effect of actually linking Venmo.

Because treatment assignment was randomized, the ITT preserves the main benefit of the randomized experiment.

---

### 3. Wald Estimator

The Wald estimator adjusts the ITT effect by the difference in compliance rates between treatment and control.

**Wald = (E[Y | T=1] - E[Y | T=0]) / (E[C | T=1] - E[C | T=0])**

From the data:

- ITT effect = **0.2489**
- Treatment compliance rate = **0.0428**
- Control compliance rate = **0**

Therefore:

**Wald = 0.2489 / 0.0428 = 5.82**

The estimated Wald effect is:

**Wald Estimate = $5.82**

Under the standard instrumental-variable assumptions, this can be interpreted as the estimated treatment effect for users whose decision to link Venmo was caused by being offered access to the feature.

This is also known as the **Local Average Treatment Effect (LATE)**.

---

### 4. Bootstrap Standard Error

To measure the uncertainty of the Wald estimate, the entire Wald estimator was bootstrapped using **10,000 iterations**.

Treatment and control groups were resampled separately with replacement so that every bootstrap iteration preserves the original experimental structure:

- 5,000 treatment observations
- 5,000 control observations

For each bootstrap sample, we recalculated:

1. The treatment-control difference in average revenue
2. The treatment-control difference in compliance
3. The Wald estimator

This generated 10,000 bootstrap Wald estimates.

The standard deviation of these bootstrap estimates was:

**Bootstrap SE = 2.72**

The relatively large standard error is mainly driven by the very low compliance rate.

---

### 5. Compliance-Based Filtering

The variable `signal` predicts the probability of compliance.

Higher values of `signal` indicate that a user is more likely to link Venmo.

We therefore filter users using several signal thresholds:

- 25th percentile
- 50th percentile
- 75th percentile
- 95th percentile

The same threshold is applied to both treatment and control groups.

The goal is to determine whether focusing on users who are more likely to comply can improve the precision of the Wald estimator.

There is an important trade-off:

**Higher signal -> higher compliance -> potentially lower variance**

but also:

**Higher signal threshold -> smaller sample size -> potentially higher variance**

---

## Variance and the np² Measure

The approximate variance of the Wald estimator can be written as:

**Var(Wald) ≈ 2σ² / (np²)**

where:

- `n` = number of treated observations
- `p` = compliance proportion
- `σ²` = outcome variance

The compliance proportion is calculated as:

**p = number of treatment users who complied / number of treatment users in the subset**

Holding the outcome variance fixed:

**Larger np² -> smaller variance -> smaller standard error**

Therefore, `np²` provides a simple way to evaluate the trade-off between compliance and sample size.

---

## Key Findings

| Signal Threshold | Treated Users (n) | Compliance (p) | np² |
|---|---:|---:|---:|
| 25th percentile | 3,773 | 5.43% | 11.14 |
| 50th percentile | 2,497 | 7.21% | 12.98 |
| 75th percentile | 1,266 | 10.35% | **13.56** |
| 95th percentile | 249 | 20.08% | 10.04 |

As the signal threshold increases, the compliance rate increases substantially.

However, the sample size also decreases.

The largest `np²` value occurs at the **75th percentile threshold**.

Therefore, among the thresholds considered, the 75th percentile provides the best balance between:

- increasing compliance
- maintaining a sufficiently large sample

Based on the variance approximation, this threshold is expected to produce the smallest standard error.

---

## Main Takeaways

- Random treatment assignment does not imply random compliance.
- As-Treated and Per-Protocol estimates can suffer from selection bias.
- ITT preserves randomization and estimates the effect of being offered treatment.
- The Wald estimator adjusts the ITT effect for imperfect compliance.
- Very low compliance makes the Wald estimate noisy and increases its standard error.
- Filtering on a predictor of compliance can improve precision.
- Filtering too aggressively can reduce the sample size too much.
- In this experiment, the **75th percentile signal threshold** provides the best balance between compliance and sample size.
